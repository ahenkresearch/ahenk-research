# AHENK App Store Website

GitHub Pages-ready static website.

## Publish
1. Create a public GitHub repository, e.g. `ahenk-research`.
2. Upload all files to the repository root.
3. Open GitHub → Settings → Pages.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Use the public URL GitHub gives you.

## App Store Connect
- Support URL: public site URL + `/support.html`
- Privacy Policy URL: public site URL + `/privacy.html`
- Marketing URL: optional; use the root URL.
